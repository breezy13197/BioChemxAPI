Put the 20 amino acid structure images in this folder.

Filenames must be exactly these (lowercase, .png):

ala.png  arg.png  asn.png  asp.png  cys.png
gln.png  glu.png  gly.png  his.png  ile.png
leu.png  lys.png  met.png  phe.png  pro.png
ser.png  thr.png  trp.png  tyr.png  val.png

one-letter code in that box instead. Nothing breaks.
